Welcome · 3 of 3

Load a repository when you need one

There are no tabs. Workbench works on one repository at a time, and only when you ask it to.

  • Load with Ctrl+O
    From this machine, or straight from CIB GitLab — Workbench clones it first.
  • Repository tools act on it
    Graph, working copy, branches, rebase and conflicts. With nothing loaded they wait on the rail, dimmed.
  • Switch any time
    Loading another replaces it. What you follow stays on Home.

Step 2 of 4 · GitLab

Connect to CIB GitLab

Workbench talks to one GitLab, the bank’s. It needs a personal access token to read and act for you.

Set in this build
Opened in your browser
[COMPANY GITLAB URL]/-/user_settings/personal_access_tokens?name=Workbench&scopes=api,read_repository,write_repository
The page opens with these scopes ticked:
apimerge requests, pipelines, issues read_repositoryclone and fetch write_repositorypush

On the token page

  1. 1Sign in to GitLab if it asks.
  2. 2Check the name is Workbench, and pick an expiry date.
  3. 3Press Create token.
  4. 4Copy it, then come back here.

GitLab shows the token only once. Copy it before you leave the page.
